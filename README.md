# Falcon

A fast, offline code reader and editor with a complete Git client. One small server serves every
repository on your machine; each browser tab can be on a different one.

Falcon is for reading code: your own, a colleague's, a dependency's, or code generated by a tool and
changed in another terminal. It shows what changed, lets you stage or discard it piece by piece, and
gets out of the way. It has no AI, makes no network calls, and runs nothing but `git` and the language
servers you already installed.

```sh
falcon ~/code/app ~/code/api      # then open http://127.0.0.1:7700
```

## What it does

**Read**
- Opens any file instantly, however long: the viewer fetches only the lines on screen, highlighted.
- ⌘-click (Ctrl-click) or F12 goes to a definition; ⇧F12 finds references; Alt-← goes back.
- Rest on a name for its signature and documentation; problems are underlined (with a language
  server installed: gopls, clangd, basedpyright/pyright, TypeScript, jdtls, rust-analyzer).
- Go to file (⌘P, `name:line`), go to symbol (⌘T: every declaration in the folder, from an index kept on
  disk and refreshed as files change), search the folder as you type (⌘⇧F: case, whole word, regex, file
  patterns), outline of the open file, links to a line (`/r/<folder>/#path:line`).

**View every kind of file**
- Markdown rendered (tables, task lists, highlighted code, images from the folder, links that open other
  files); Preview and Source side by side in one click.
- Images with zoom and real size, SVG (shown safely, source a click away), PDF (the browser's own
  viewer), audio, video, font specimens, CSV/TSV as tables, and a clear card for any other binary.

**Change**
- Edit and save; a file changed on disk by another tool after you opened it is never overwritten.
- Open files follow changes made elsewhere as they happen.

**Git** (everything VS Code's Source Control does)
- A diff view after the best Git clients: inline or side by side, syntax highlighted, with the changed
  characters inside each line marked; whole-file context on demand; jump between changes with [ and ].
- Stage, unstage and discard whole files, single hunks, or chosen lines (click line numbers, shift-click
  a range); a change that moved since you saw it is refused rather than applied blindly.
- History as a commit graph across every branch, with branch, remote and tag labels.
- Commit (all, or what is staged), amend, undo the last commit.
- Push, pull, fetch, sync, publish, force push with lease, ahead/behind; your own credentials.
- Branches (create, switch, rename, delete, check out from a remote, merge), merge conflicts (keep a
  side, mark resolved, commit or abort), stashes, remotes, history with per-commit diffs.
- Updates on its own when the repository changes from a terminal or another tool.

**Look**
- Dark and light themes: follows the system, or pick one from the activity bar (remembered).
- File icons from the same line-icon family as the rest of the UI, tinted by language.

**Many folders, one server**
- ⌘K switches the folder in this tab; ⌘↵ opens it in a new tab. Folders added from the UI (with a
  folder browser) or the command line are remembered.

## Build and install

Falcon is one program you build yourself in a minute. You need [Go](https://go.dev/dl/) 1.26 or newer
to build it and [Git](https://git-scm.com/) to run it; the UI is prebuilt in `web/dist`, so nothing else.

**Windows** (PowerShell):

```powershell
winget install --id GoLang.Go -e; winget install --id Git.Git -e   # if you don't have them
git clone https://github.com/vrohitv/falcon; cd falcon
.\build.ps1 -Install      # builds falcon.exe and puts it on your PATH (no administrator rights)
falcon -open C:\code\my-project
```

**macOS and Linux:**

```sh
git clone https://github.com/vrohitv/falcon && cd falcon
./build.sh               # builds ./falcon; copy it anywhere on your PATH
./falcon -open ~/code/my-project
```

**With Go alone:** `go install github.com/vrohitv/falcon/cmd/falcon@latest`

Changing the UI needs Node.js: `.\build.ps1 -Web` or `./build.sh --web` (or `make build`).

## Run

```sh
falcon -open ~/code/app ~/code/api      # serves both; opens the browser
```

| Flag | Default | |
| --- | --- | --- |
| `-listen` | `127.0.0.1:7700` | Address. Anything other than loopback requires `FALCON_TOKEN` (24+ characters). |
| `-data` | your config folder `/falcon` | The folder list and language-server indexes. |
| `-lsp` | `true` | Run installed language servers. |
| `-open` | `false` | Open Falcon in your browser once it is listening. |
| `-assets` | built in | Serve the UI from a folder (development). |

Without arguments Falcon serves the folders it served last time, or the current folder.

## Design

- **Go server** (`internal/`): `workspace` (the folders), `repository` (files, Git, diffs, hunks),
  `ide` (highlighting with Chroma, windows of large files, fuzzy file search), `lsp` (a pool of
  language servers kept running), `outline`, `server` (HTTP; every folder under `/api/r/<id>/`).
- **Index** (`internal/index`): per folder, the file list (served from memory, refreshed in the
  background) and every declaration (for definitions and go to symbol), parsed in parallel, refreshed
  incrementally by file size and time, and saved to disk so a restart starts warm. Search is `git grep`,
  narrowed while you type to the files the previous keystroke matched.
- **Svelte UI** (`web/`), built into the binary. Fonts are bundled; the page's security policy allows
  nothing but Falcon itself.
- Security: loopback only by default, same-origin requests only, `.git` is never served or written,
  Git hooks and content filters never run, credentials are never prompted for.

## Speed

On a synthetic 20,000-file repository (173 MB), from memory: file list 4 ms, go to file 1 ms, go to
definition 1 ms, go to symbol 9 ms; Source Control status about 130 ms; full-text search about 0.13 s
through the text index (0.4 s without it). On a few-hundred-file repository searches take 10–20 ms.
Indexes of folders not used for 30 minutes are released from memory; removing a folder deletes them. The symbol index builds in about a second and loads in about 0.3 s after a restart.
Large JSON answers and the UI are sent compressed.
